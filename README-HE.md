# מקליט שיחות – Android

גרסת אב-טיפוס ראשונה לאפליקציה בעברית.

## מה יש כרגע
- מסך בעברית.
- התחלה ועצירה ידנית של הקלטת מיקרופון.
- שמירת קובצי M4A בתיקיית האפליקציה.
- רשימת הקלטות וניגון.

## מגבלה חשובה
האפליקציה משתמשת במיקרופון בלבד. ב-Android 11 ובמכשירים רבים, אפליקציה רגילה אינה יכולה לגשת ישירות לאודיו הפנימי של שיחת הטלפון. לכן ייתכן שיוקלט רק צד אחד או שלא תתאפשר הקלטה בזמן שיחה. אין כאן הבטחה להקלטה אוטומטית או להקלטת שני הצדדים.

## בנייה
פתחי את הפרויקט ב-Android Studio, המתיני לסנכרון Gradle, ואז Build > Build APK(s).
