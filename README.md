# מקליט שיחות – Android

פרויקט לאפליקציית Android בעברית לניהול הקלטות שיחה.

## חשוב לדעת

ב-Android 11 קיימות מגבלות מערכת ויצרן על הקלטת אודיו של שיחות טלפון. לכן אין אפשרות להבטיח הקלטה של שני הצדדים בכל מכשיר. יש לבדוק את ההתנהגות בפועל במכשיר A95 ולפעול בהתאם לחוק ולדרישות ההסכמה והפרטיות.

## תכנון ראשוני

- ממשק בעברית.
- רשימת הקלטות לפי תאריך ושעה.
- ניגון, שיתוף ומחיקה של הקלטות.
- טיפול בהרשאות ובשגיאות בצורה ברורה.
